| B04 | Alternatives | Two separate puzzle pieces: "Sandboxes — E2B" and "Traces & scores — Langfuse". Langfuse is a tool that records LLM traces and scores them. Each covers one piece. Mine will join sandbox, trace, and check into one small loop you run on your own machine, where pass or fail comes from tests run inside the sandbox, not from another model's opinion. |
| B05 | Who opens it | A 60-second stopwatch. README → one command → a small results table (task, pass/fail, reason).
